SEMANA 9 · PRINCIPIO ARQUITECTÓNICO

Lógica Imperativa vs. Construcción Dirigida por Datos

En lugar de preguntarnos '¿Qué código debemos escribir?', preguntamos '¿Qué configuración debemos leer?'

// ❌ ANTES: Alta complejidad ciclomática. Recompilación y redespliegue ante cada cambio de regla. if (method !== 'EFECTIVO' && !evidence) { throw new ValidationException('Evidencia obligatoria'); } else if (method === 'PLIN' && amountCents > 150000) { throw new ValidationException('Monto excede límite diario PLIN'); } else if (receipt.status !== 'EXTRAÍDO') { if (receipt.status === 'CONFIRMADO') throw new ConflictException('Ya confirmado'); throw new ConflictException('Estado inválido para reparto'); } // Múltiples condiciones booleanas anidadas difíciles de testear y mantener...
// ✅ DESPUÉS: Búsqueda O(1) en tabla de reglas + Restricción FSM matemática + Late Binding const rule = PAYMENT_RULES_TABLE[method]; // Búsqueda directa en O(1) const isPlinActive = this.featureFlags.isEnabled('enable_plin_payments'); // Kill switch en caliente validatePaymentByRules(method, amountCents, reference, hasEvidence, isPlinActive); // Autómata FSM: previene saltos de estado ilegales matemáticamente por diseño RECEIPT_FSM.assertTransition(receipt.status, 'CONFIRMADO', receiptId);
Complejidad Ciclomática Reducción radical de bifurcaciones if/else a una única búsqueda de matriz indexada.
Enlace Tardío (Late Binding) Los parámetros se asignan en tiempo de ejecución (Runtime) evitando recompilaciones.
Principio Abierto/Cerrado (OCP) Nuevos métodos de pago se añaden agregando filas en la tabla sin tocar el motor de ejecución.

SEMANA 10 · OBSERVABILIDAD Y REGISTROS

Logs Estructurados y Contexto MDC

Mapped Diagnostic Context (MDC) como pasaporte de datos con AsyncLocalStorage

❌ Log Tradicional Plano (Inservible para analítica):
[INFO] 2026-11-20 15:45:10 - Pago registrado por usuario mateo en evento Cena

Requiere expresiones regulares frágiles; no indexa en Elastic/Loki y pierde la correlación entre hilos asíncronos.

✅ Log Estructurado en JSON con MDC (Semana 10 · Diapo 3):
{ "timestamp": "2026-11-20T20:45:10.124Z", "level": "INFO", "event": "payment.create", "trace_id": "8a3c60f7-b24a-4e92-bc91-235123d", "user_id": "usr_7712", "tenant": "event_3401", "ip_address": "192.168.1.15", "amount_cents": 4500, "method": "YAPE" }
¿Cómo se implementa MDC en Node.js sin ensuciar las firmas de los métodos?

Usamos AsyncLocalStorage. En el middleware HTTP inyectamos el contexto (traceId, userId, ip). Cualquier servicio o repositorio lee el contexto directamente del hilo asíncrono sin pasarlo como parámetro.
