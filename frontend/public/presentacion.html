REQUISITO PC3 · TOPOLOGÍA 03 / 13

Topología de Servicios Desacoplados

Aislamiento de responsabilidades para garantizar baja latencia en la interacción del usuario.

🌐 API REST Principal (NestJS + TypeScript)

Diseñada para responder en menos de 10 ms las solicitudes concurrentes de la aplicación cliente:

  • Gestión de salas de comensales, autenticación y cálculo de reparto.
  • Al recibir una boleta, responde inmediatamente con estado PROCESANDO.
  • El cliente recibe confirmación instantánea sin esperar el análisis OCR.
⚙️ Worker Asíncrono de OCR (Proceso Autónomo)

Aislado en segundo plano para no penalizar el bucle de eventos principal:

  • Consume de la cola receipt_jobs en PostgreSQL.
  • Lectura segura mediante FOR UPDATE SKIP LOCKED (sin colisiones).
  • Si Tesseract falla o una imagen es defectuosa, no afecta la disponibilidad de la API.

SEMANA 9 · AUTÓMATAS FORMALES 05 / 13

Máquina de Estados Finitos (FSM)

Garantía formal de integridad: prevención matemática de estados inconsistentes en la base de datos.

1. CARGADO
→
2. PROCESANDO
→
3. EXTRAÍDO
→
4. CONFIRMADO
Validación por Matriz de Transiciones

El sistema no permite saltos arbitrarios. Si una solicitud intenta confirmar un comprobante que aún está en estado CARGADO, la FSM intercepta la operación y retorna 409 Conflict de forma inmediata.

Definición en src/common/fsm.ts
export const RECEIPT_FSM = new StateMachine([ { from: 'CARGADO', to: ['PROCESANDO'] }, { from: 'PROCESANDO', to: ['EXTRAÍDO', 'FALLIDO'] }, { from: 'EXTRAÍDO', to: ['CONFIRMADO'] }, { from: 'CONFIRMADO', to: [] } // Inmutable ]);

SEMANA 10 · TRAZABILIDAD CONTEXTUAL 09 / 13

MDC: Mapped Diagnostic Context

Inyección y propagación transparente de contexto asíncrono sin contaminar firmas de métodos.

Estructura del Registro JSON Emitido:
{ "timestamp": "2026-11-20T21:40:12.304Z", "level": "INFO", "event": "payment.registered", "trace_id": "b4e7-91fa-4c82", "user_id": "usr_andres", "ip": "192.168.1.42", "method": "YAPE", "amount_cents": 4850 }
Mapeo Asíncrono en TypeScript

En Java se emplea org.slf4j.MDC con ThreadLocal. En Node.js/TypeScript se implementa mediante AsyncLocalStorage:

  • Un middleware HTTP genera e inyecta el trace_id.
  • Cualquier servicio o repositorio accede al contexto sin pasarlo como argumento.
  • Permite correlacionar de inmediato incidentes reportados por usuarios.
